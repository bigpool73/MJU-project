# AI 사용 내역서 (AI Usage Ledger)

2026학년도 AI 리터러시 경진대회 출품 프로토타입.
과제에 쓴 생성형 AI를 학생이 기록하면, **교수 정책 범위 점검 + 비판적 검증 점검**이 붙은 제출용 내역서를 만들어 주는 웹 서비스.

## 해결하려는 문제
- 교수마다 AI 허용 범위가 달라 학생은 어디까지 써도 되는지 모른다.
- 사용했더라도 “ChatGPT 사용함” 한 줄로 끝나, 교수는 학생이 AI 답변을 검증했는지 알 수 없다.

## 기능
| 기능 | 설명 |
|---|---|
| 정책 설정 | 과제별 허용 범위(금지 / 학습 보조 / 구상·피드백 / 폭넓게)를 선택 |
| 사용 기록 | 도구, 목적, 프롬프트, 답변 요약, 반영 방식, **직접 검증 방법**, **본인이 고친 부분** |
| 실시간 점검 | 정책 범위를 넘는 용도, 검증 없이 반영, 수정했다면서 내용 미기재 등을 입력 중 바로 안내 |
| 내역서 | 요약 통계·용도별 사용·자동 점검 결과·상세 기록·성찰·서명란, 인쇄/PDF 저장 |
| 변조 탐지 | 기록을 해시 체인으로 봉인. 제출한 `.json`을 ④ 교수용 검증에 올리면 사후 수정 여부 확인 |

모든 데이터는 브라우저(localStorage) 안에만 저장되며 서버로 전송되지 않는다.

## 실행
```bash
# 빌드 불필요. 정적 파일이므로 index.html을 열거나
python3 -m http.server 8000   # http://localhost:8000
# 로직 테스트
node --test test/core.test.js
```

## 구조
- `src/core.js` 정책·검증 점검, 통계, 해시 체인 (순수 로직, 테스트 대상)
- `src/app.js` 화면
- `docs/proposal-notes.md` 공모전 평가 기준 매핑

## 한계 (솔직하게)
- 기록이 **작성된 뒤** 바뀌었는지는 탐지하지만, 학생이 쓰지 않은 AI를 썼다고 적거나 쓴 것을 빠뜨리는 것은 막지 못한다.
- 따라서 부정행위 판정 도구가 아니라, 학생의 자기 보고와 검증 습관을 드러내는 도구로 설계했다.
